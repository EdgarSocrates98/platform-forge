# Economy Closure Polish — Baseline Audit (prompt_evo_polish §2)

Audited `main` at HEAD `7d80313` (post-economy closure). Every gap below
was confirmed against code, not assumed.

## Receipt drift — CONFIRMED (Blocker 1)

`VALIDATION-RECEIPT.json` binds `sha: [1ab6a97]` — the commit *before*
the closure commit `7d80313`. The receipt validates a tree that is not
HEAD. Additionally the field name `sha` is ambiguous (validated? closure?
generation-time?) — §6 requires `validated_sha` semantics.

## Gate taxonomy drift — CONFIRMED (Blocker 2)

Canonical source `scripts/validate.py` defines 12 economy gates:
`economy-contracts|cache|context|budget|resume|reconcile|routing|agentic|
verification|qpt|evals|surface`.

The committed receipt uses a **handwritten parallel taxonomy**:
`economy-gateway`, `economy-pricing-verify`, `economy-cli`,
`economy-mcp`, `economy-doctor`, `economy-fleet-qpt` — none of these are
gate names — plus generic `tests|lint|docs|lab|evals|validate`. A gate
could be renamed or deleted in the validator and the receipt would not
notice (§11 violation).

## Reproduce command drift — CONFIRMED (Blocker 3)

Six reproduce paths in the committed receipt point to files that do not
exist: `test_context_gateway.py`, `test_economy_checkpoint.py`,
`test_economy_reconcile.py`, `test_economy_pricing.py`,
`test_economy_verifyplan.py`, `test_mcp_economy.py`. A reviewer running
the receipt's own reproduce commands hits dead paths — the receipt fails
its own contract (§15–19).

## Routing authority map — CONFIRMED (Blocker 4)

- `routing/router.py::route(signal)` → plain dict (`mode`, `specialists`,
  `reasons`, `fallbacks`) — the deterministic router.
- `routing/decision.py` — `RoutingRequest`/`RoutingDecision`/`receipt`/
  `promote_verdict` dataclasses, **no `decide()` producer**: the decision
  is assembled inline by `cli/main.py::_decision_from_route` AND
  `mcp/tools.py` (two adapters, duplicated logic — drift surface).
- `economy/engine.py::EconomyEngine.strategy()` → returns route-shaped
  vocabulary (`single-specialist`, `coordinated`, `multi-specialist`)
  with no marker distinguishing it from a routing decision — a parallel
  authority in appearance (§23).
- `agents/orchestrator.py::prepare()` accepts `router_decision` as an
  opaque dict — no schema enforcement; an EconomyEngine strategy dict
  would be stored as if it were a canonical decision.

## Remote CI — externally blocked (§66–69)

`gh run list` on `main`: every job failed in 1–3s with annotation
*"The job was not started because recent account payments have failed or
your spending limit needs to be increased."* Classification:
`externally-blocked (billing)` — not code failure, not "CI green".
