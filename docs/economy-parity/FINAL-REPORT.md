## Receipt semantics (§5–8, §62–65)

`validated_sha` is the functional commit; `closure_sha` is null inside
the committed file because the receipt-only commit cannot contain its
own hash. The `economy-receipt` gate accepts `validated_sha == HEAD`
(pre-closure) or `HEAD~1` (receipt-only commit on top). Gate names in
the receipt are exactly the validator's `economy-*` keys — aliases are
forbidden and tested (`TestGateNameParity`). Every `reproduce` field is
the actual executed command; dead test paths fail the receipt gate and
`tests/test_economy_closure.py`.

## Routing authority (§20–29)

One canonical authority: `routing/decision.py::decide()` produces the
only `RoutingDecision` (`platformforge/routing-decision/v1`). CLI and
MCP both call it — the duplicated inline adapters were removed.
`EconomyEngine.advice()` returns `economy-advice/v1` marked
`advisory: true`; `strategy()` is a deprecated alias. The orchestrator
refuses any `router_decision` lacking the canonical schema — economy
advice cannot activate a route (tested, adversarial P4).
