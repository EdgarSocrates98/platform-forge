# Code of Conduct

Be respectful, precise, and evidence-first — the same standard the
codebase holds itself to.

- Critique claims, not people. Disagreement cites evidence.
- No harassment, discrimination, or personal attacks.
- Security issues go through [SECURITY.md](SECURITY.md) — never public
  issues.
- Maintainers may remove contributions or participants that violate
  this standard.

Scope: all project spaces — issues, PRs, discussions, and any
representation of the project.
